# GMC QR License Page

This project contains one sample GitHub Pages URL:

`/qr/01kq9/`

## Deploy

1. Create a GitHub repository, e.g. `gmc`.
2. Upload the contents of this folder to the repository root.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main`, and select `/ (root)`.
5. Save.

Your page will then be available at:

`https://YOUR-USERNAME.github.io/gmc/qr/01kq9/`

Replace `YOUR-USERNAME` and `gmc` with your GitHub username and repository name.
